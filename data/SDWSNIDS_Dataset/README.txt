# Dataset README

## Overview
This README file provides information about the Dataset of the project title: AI-Based Intrusion Detection & Prevention in Edge-Assisted SDWSN with Modified Honeycomb Structure (HieMultiBlock). 
This dataset contains simulations codes taken after simulation.

## Content
The dataset includes the following files and directories:

- `Source Code`: Contains the main source code (src/scratch) 
- `Video`: Contains a simulation video, how the project works.
- `Link to the Video`: https://youtu.be/CnscobLPw90
